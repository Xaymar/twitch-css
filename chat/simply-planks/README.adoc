= Simply Planks =
Make your chat look like it was written on wooden planks. 

== Installation / Usage ==
1. Add / Edit a Chat Browser Source and point it at `https://twitch.tv/popout/YourTwitchChannelName/chat` and replace YourTwitchChannelName with your actual twitch channel name.
2. Copy the contents of `style.css` and paste it into the Custom CSS field
3. Adjust the font size to match your canvas and stream resolution.
4. Done

=== Notes === 
- The style was designed for a 3840x2160 canvas shown on a 1280x720 mobile phone at normal watching distance.
